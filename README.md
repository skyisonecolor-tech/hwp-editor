# 한글 쪽 편집기 (HwpPageTool)

한글(HWP·HWPX) 파일을 **통합 · 쪽 추출 · 쪽/파일 순서 변경 · 쪽별 분할**하는 Windows 프로그램입니다.
한컴오피스 한글을 자동으로 조작(COM)해서 처리하므로 **한글이 설치된 PC**에서만 동작합니다.
원본 파일은 바뀌지 않습니다.

## 1. exe 만들기

### 방법 A — 내 PC에서 (build.bat)
1. Python 3.10 이상 설치 (설치 화면에서 **Add python.exe to PATH** 체크)
2. 이 폴더의 `build.bat` 더블클릭
3. `dist\HwpPageTool.exe` 가 만들어짐 → 이 파일 하나만 복사해서 쓰면 됩니다.

### 방법 B — GitHub에서 자동으로
1. 이 폴더를 GitHub 저장소에 올립니다(`.github` 폴더 포함).
2. 저장소 **Actions → Build Windows exe → Run workflow** 실행
3. 완료되면 실행 결과 화면 아래 **Artifacts**에서 `HwpPageTool` 다운로드
   (`v1.0.0` 같은 태그를 올리면 Releases에도 자동 등록)

> 한글 없이 화면만 보고 싶으면 `run_test_mode.bat` (또는 `HwpPageTool.exe --fake`)

## 2. 사용 방법

| 하고 싶은 일 | 방법 |
|---|---|
| **여러 파일 통합** | 파일을 끌어다 놓고 → 저장하기 |
| **파일 순서 변경** | 왼쪽 목록에서 파일을 끌어 옮기거나 ▲▼ / 이름순 |
| **쪽 순서 변경** | 오른쪽 쪽 그림을 끌어 옮기기, 맨 앞으로/맨 뒤로, 순서 뒤집기 |
| **쪽 추출** | 쪽 선택(Ctrl·Shift+클릭) → ‘선택 쪽만 남기기’ → 저장 / 또는 ‘쪽 범위로 추가’(예: `1-3, 5, 8-`) |
| **쪽 빼기** | 쪽 선택 → Delete |
| **쪽마다 따로 저장(분할)** | 저장 방식 ‘쪽마다 따로’ 선택 → 폴더 지정 |
| **형식 변환** | 형식에서 HWP / HWPX / PDF 선택 |

- 쪽 그림을 두 번 누르면 크게 볼 수 있습니다.
- 쪽 그림 테두리 색 = 원본 파일 색(왼쪽 목록의 점 색).
- 오른쪽 클릭 메뉴에 ‘선택 쪽만 바로 저장’도 있습니다.

## 3. 알아 둘 점

- 한글 파일에는 ‘쪽’이 저장되어 있지 않아 한글 프로그램이 계산한 쪽을 기준으로 자릅니다.
  - **여러 쪽에 걸친 표**는 중간에서 나눌 수 없어, 표가 이어지는 다음 쪽 묶음에 함께 들어갑니다.
  - 중간 쪽만 추출할 때 첫 문단에 있는 머리말·꼬리말·쪽 번호 설정은 유지하도록 처리했습니다.
- 같은 파일의 연속된 쪽(예: 3~5쪽)은 한 덩어리로 추출해서 배치가 최대한 유지됩니다.
- 합칠 때 각 조각은 ‘구역’으로 붙으므로 원본의 용지 설정이 조각마다 유지됩니다.
- 작업할 때마다 한글이 **“파일 접근 허용”** 창을 띄우면 **[모두 허용]** 을 누르세요.
  (한컴 개발자 사이트의 *보안 승인 모듈*을 등록해 두면 이 창이 뜨지 않습니다.)

## 4. 문제가 생기면

1. **설정 → 한글 연결 시험…** : 2쪽 이상인 한글 파일 하나로 각 기능(열기, 쪽 계산, 미리보기, 추출, 통합, PDF)을 점검해 ✔/✘로 보여 줍니다.
2. **설정 → 작업 중 한글 창 보이기** : 한글이 어디서 멈추는지 눈으로 확인할 수 있습니다.
3. **설정 → 기록(로그) 폴더 열기** : `hwptool.log` 파일에 자세한 오류가 남습니다.

## 파일 구성

```
main.py            실행 시작점
app/engine.py      한글 COM 자동화(쪽 경계 계산, 추출, 통합, 미리보기, 시험)
app/planner.py     결과 쪽 목록 → 추출/통합 작업 계획
app/worker.py      한글 작업을 별도 스레드에서 처리, 미리보기 저장소
app/gui.py         화면(PySide6)
build.bat          exe 만들기
.github/workflows  GitHub에서 exe 자동 빌드
```
